# Portafolio Profesional - Actividad Integradora 1

## Nombre del Proyecto
Portafolio Web Personal y Profesional - Programación de Sistemas Web

## Nombre del Estudiante
* **Juan Carlos Artos Cuesta**

## Descripción Breve del Portafolio
Sitio web personal desarrollado como portafolio profesional para presentar la trayectoria académica como Tecnólogo en Sistemas y estudiante de Ingeniería en Sistemas Inteligentes. El sitio incluye información detallada sobre mi experiencia en el sector público (EPMTTTSV y CNE) y una sección dedicada a exhibir aplicaciones web y plataformas tecnológicas reales desarrolladas en el ámbito profesional e independiente (Sertycont, LaCarta, ZonaParking, SICGET y Gestión de Placas).

## Tecnologías Utilizadas
* **HTML5:** Maquetación estructurada mediante etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `footer`).
* **CSS3:** Estilos avanzados con diseño minimalista inspirado en interfaces modernas, variables globales en `:root`, maquetación flexible con Flexbox y efectos interactivos mediante la pseudoclase `:hover`.
* **JavaScript:** Interactividad en el frontend y validación de formularios de contacto.
* **FontAwesome:** Integración de iconografía vectorial para habilidades y accesos rápidos.
* **Git y GitHub:** Control de versiones estructurado mediante commits progresivos que evidencian el avance del desarrollo.

## Proyectos Destacados Incluidos
1. **Sertycont:** Sistema web de gestión para firmas contables y asesoría empresarial con bóvedas de credenciales y facturación electrónica.
2. **LaCarta:** Plataforma SaaS multiusuario de menús digitales y KDS con notificaciones en tiempo real vía FCM y pagos electrónicos.
3. **ZonaParking (SERTT):** Plataforma digital para el control de estacionamiento rotativo tarifado municipal integrada con terminales POS.
4. **SICGET:** Sistema web institucional de gestión, recaudación y tránsito para EPMTTTSV.
5. **Gestión de Placas y RTV:** Portal web para permisos provisionales de circulación e inventario vehicular.

## Instrucciones para Visualizar el Proyecto
1. Clona este repositorio o descarga los archivos comprimidos del código fuente.
2. Abre la carpeta del proyecto en tu editor de código de preferencia (ej. Visual Studio Code).
3. Abre el archivo principal **`index.html`** directamente en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
